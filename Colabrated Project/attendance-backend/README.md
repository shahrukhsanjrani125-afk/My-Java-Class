# Attendance Management System - Backend

## Setup
1. Copy .env.example to .env and fill in values.
2. Run `npm install`
3. Run `npm run build`
4. Use CLI commands:
   - `npm run cli -- start`
   - `npm run cli -- create-admin -e admin@test.com -p Admin@123`
   - `npm run cli -- seed -c 50`
   - `npm run cli -- migrate`
