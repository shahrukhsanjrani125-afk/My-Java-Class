# Paradise Nursery Shopping Application

Paradise Nursery is a React-based online houseplant shopping application.

## Project Features

- Paradise Nursery landing page
- Get Started button
- About Us page
- Plant product listing
- Three plant categories
- 18 unique houseplants
- Plant thumbnails, names, and prices
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease quantities
- Remove products from cart
- Individual item total calculation
- Overall cart total calculation
- Continue Shopping functionality
- Checkout Coming Soon message

## Redux Cart Management

The application uses Redux Toolkit to manage shopping cart state.

The CartSlice provides these reducer functions:

- addItem()
- removeItem()
- updateQuantity()

## How to Run

Install dependencies with npm install.

Start the development server with npm run dev.

Create a production build with npm run build.

## Project Purpose

Paradise Nursery demonstrates a complete React shopping workflow using component-based development, React Router, Redux Toolkit, and responsive CSS.
